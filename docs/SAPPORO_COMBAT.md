# 札幌の4フェーズ市街戦

HOMEのマップまたは出撃前確認で札幌を選択する。知床の導入進行に関係なく選択可能。PCのWASD、マウス視点、左クリック射撃、Rリロード、1/2/3武器変更、Escポーズを使用する。

| フェーズ | プレイ中の経過時間 | 出現内容 |
|---|---|---|
| 1 | 0分 | 人型25体・ドローン25体を市街地に分散 |
| 2 | 5分 | 人型25体・ドローン25体を追加（通常敵は累計100体） |
| 3 | 10分 | テレビ塔の足元に小ボス「電纏蜘蛛」、HP1000 |
| 4 | 15分 | 札幌駅前に中ボス「氷路開拓機」、HP1000 |

時間はゲームを操作している間だけ進む。ポーズ、非表示、停止中に増援時間は進まない。後半2フェーズに通常敵の追加はない。ボス2体を撃破すると札幌駅の制圧完了。通常敵の全滅は勝利条件にしない。

6つのチェックポイントは、すすきの南の進入地点、すすきの交差点、大通公園、テレビ塔、時計台、札幌駅。幅0.76mの水色の地面ラインと矢印が、実際に歩ける道路・通路を結ぶ。塔の台座や駅の建物内を避け、ボス戦はその手前の広場で行う。各広場には外周リング、目印の灯、当たり判定付きの遮蔽物を設けた。

ボスは該当フェーズで初めて表示・攻撃対象になる。出現位置ではプレイヤーと建物の重なりを避ける。敵とボスにHPバー、命中時にダメージ数を表示する。プレイヤーのHPと将来用のシールド欄は既存の表示を使用。弾薬の予備は無制限、マガジンとリロードは維持する。

倒された場合は進入地点から再挑戦する。再挑戦では50体・フェーズ1・ボス未出現に戻し、知床の導入や達成記録を消さない。札幌への直接出撃は、知床や他地域をクリアした記録を付与しない。戦闘の敵HP・フェーズは保存しないため、出撃し直すとフェーズ1から始まる。

## 素材と配信

編集元の地形はRECLAIM/日本各地/札幌/札幌_3D/、動作モデルはmotion/characters/の札幌ボス。元のBlender・GLBは上書きしない。ゲーム配信はpublic/sapporo-map/とpublic/sapporo-bosses/を使用する。manifestに元・配信ファイルのハッシュと出典を記録。

街の頂点・面・材質は保ったままmeshoptとgzipで配信する。遠い通常敵はAI処理とモデル生成を抑え、近づくと有効にする。知床と札幌の地形データは出撃先だけを遅延読込する。配布HTMLには両地域の素材を埋め込み、file://で動く。

開発専用の?sapporo-previewは、debugの札幌プレビューでのみフェーズ間隔を3秒に短縮する。本番と配布HTMLの通常プレイは各5分。
