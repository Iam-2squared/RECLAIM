# 内部処理の軽量化

マップ・モデル・配置・描画距離を維持したまま、描画命令と毎フレームの重複処理を減らした。マップやモデルの削除、ポリゴン削減、テクスチャの縮小は行っていない。

## 変更内容

- 静止マップの同じ材質を共有し、同じ領域の部品をまとめて描画。静止物の行列更新、停止中の可視範囲再計算、統計用の全体走査を省略した。圧縮マップの展開時も不要なコピーを減らした。
- 人型・ドローンの同じ材質の部品をまとめて描画し、元の動作と全三角形を維持した。
- 視線判定の一時オブジェクト生成と過大な検索範囲、物理判定の重複計算、敵の経路計算の繰り返しを削減した。射撃用の検索範囲は維持している。
- 一時停止後は必要な画面更新を終えると継続的な `requestAnimationFrame` を停止する。弾と残存軌跡がない間は弾道処理を省略する。

## 比較結果

同じマップ・モデル・カメラ、1280×720、DPR 1、balanced設定で、敵を固定配置した比較用プローブの結果。

| 測定項目 | 変更前 | 変更後 |
| --- | ---: | ---: |
| 敵50体：描画命令数 | 3,551 | 576（83.8%減） |
| 敵50体：シミュレーション処理時間 | 219.4 ms | 24.0 ms |
| 敵2体：描画命令数 | 335 | 168 |
| マップの材質数 | 88 | 9 |
| 地形・建物の描画メッシュ数 | 76 | 47 |
| 人型Lv.1単体：描画命令数 | 67 | 6 |
| ドローンLv.1単体：描画命令数 | 63 | 7 |

これは処理負荷を比較するための測定値で、実際のプレイ中のFPSを保証するものではない。CPU時間は端末・同時実行処理などの影響を受ける。記録は [before.json](./performance/before.json) と [after.json](./performance/after.json) を参照。

## 維持を確認した内容

- 家・庭・倉庫・遠景・山の5視点で、変更前後のPNGがバイト単位で一致した。地形12件、建物64件、植生3,330個、全頂点・法線・UV・色・三角形を維持している。[マップ検証](./performance/world/check.json)
- 人型の歩行、ドローンの巡回・死亡の比較画像は一致した。人型の死亡画像は1ピクセル（0.00038%）だけ差があり、全モデルの三角形数は同一。[モデル検証](./performance/actor-batches.json)
- 全48,582個の衝突判定データのハッシュが一致した。1,738点の物理問い合わせ結果、および240秒・50体の敵シミュレーションの移動結果も変更前後でハッシュが一致した。[全衝突判定](./performance/ai-physics-collider-equivalence.json)、[変更前](./performance/ai-physics-before.json)、[変更後](./performance/ai-physics-after.json)
- 配信用マップの元データを変更せず、圧縮データの復元・整合性、描画属性の一致、静止中の更新省略を専用テストで確認した。
