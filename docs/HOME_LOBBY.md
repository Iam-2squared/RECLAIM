# HOME / 4人ロビー

2026-10-26。提供された初期Fortniteのロビー画像を配置の基準に、RECLAIM用の上部タブ、探索情報、出撃確認へ置き換えています。承認済みスタート画面の構図は維持します。

## 表示と操作

中央には実際のJonesyとRamirezを表示します。`motion/characters/Jonesy`と`motion/characters/Ramirez`の更新されたGLBから、形状・骨格・UVと10種類の動作データを保ち、テクスチャの解像度を配信用に調整しています。保存元・ハッシュ・処理内容は`public/home-models/manifest.json`を参照してください。HOMEでは提供された`Idle`を個別のAnimationMixerで再生します。

Ramirezの更新GLBには顔の頂点法線が乱れる箇所がありました。読込後に顔の法線だけを再計算し、黒い斑点状の陰影を補正します。GLB原本、形状・UV・動作は変更しません。

初回は4人のローカル編成プレビューです。ソロ、空き枠の追加ボタン、4人編成で1～4人に変更できます。現在ある2種類のモデルを複製して並べます。オンラインの参加者や準備完了を偽装しません。左のオペレーター選択で自分のモデルを切り替え、選択と人数は`reclaim.lobby.v1`に保存します。

上部のマップ・キャラ設定・武器・ボス状況・ランキングは既存の実機能に接続します。マップの18地点、未到達情報の非公開、装備・名前・進行の保存を維持します。プレイは出撃前確認を開き、明示的な出撃で本編を開始します。

武器欄は新しく提供されたアサルト・スナイパー・サバイバルナイフの3種類です。銃の主・副枠と、固定の近接枠を分けています。提供された実モデルのプレビューはHTMLに含め、GLB原本の配信用コピーと出典ハッシュは`public/home-weapons`に保存します。旧小銃の保存は有効な銃枠を維持しながら移行し、名前・アクセント・持つ枠は保持します。出撃後は実モデルの武器と既存の射撃・装填・近接・視点切替を使用します。

## 背景

初回は提供画像に近い青い背景と床のグリッドです。`src/home-regions.ts`の`HOME_BACKDROPS`が地域ごとの名称・色・任意の背景画像を管理します。実際のcheckpointの地域を使用し、保存がないときは知床です。新しい町域や背景画像はこの定義に追加します。ロビーで背景を変えるために進行を更新することはありません。

## 更新された知床マップ

「プレイ → 出撃開始」、または「マップ → このマップに出撃」で、更新された知床の実マップに入れます。`map/知床_高画質版`の最新の地形・家・庭・道・山道・廃倉庫・荒れた畑・廃バス・紫の嵐空を使用します。初回は家の1階から始まり、ラジオを聞き、玄関と庭を通って外へ歩けます。WASD移動・Shiftダッシュ・Spaceジャンプ・マウス視点に対応します。

地形と床・階段は実際の三角形から高さを計算し、壁・戸口・手すり・樹木・岩に当たり判定を追加しました。上階へ突然移動しないよう現在の足の高さに対応する床を選びます。水面と霧の境界を越える移動は止めます。実コントローラーで家の玄関、ポーチ、2階への階段、山道を含む1,648mの移動を確認しています。

PCはウィンドウの幅に関係なく出撃できます。探索中はボタンを押さず、マウスを動かすだけで視点が動きます。マウス固定が使えない表示でも同じ操作に対応し、画面の端に達すると旋回方向を保持します。マウスが画面外へ出て追加イベントが届かなくても旋回を続け、中央への移動・操作ボタンへの移動・Escで停止します。画面非表示・フォーカス喪失でも停止し、復帰時の座標飛びと遅れたマウス固定通知による勝手な再開を防ぎます。出撃前の地形読み込みは中止可能です。新しい座標系の進行は`reclaim.campaign.shiretoko-authored-20261026.v1`へ保存し、以前のマップの保存は残します。装備・表示名・ロビーの保存は引き続き使用します。

「3Dマップを見渡す」は全体を眺める補助機能です。全体表示からも「このマップに出撃」で探索へ移れます。通常配信は開くときだけ読み込み、全体表示を閉じるとiframeを破棄します。ゲームプレイと全体表示は同じ埋込地形データを共有し、単独HTMLにも1回だけ同梱します。

## 重なりの修正

低い画面では左の情報欄を圧縮し、高さを制限して装備欄との重なりを防ぎます。横長の小画面ではキャラ名の補助表示を減らし、ステージを操作欄の間に収めます。名前の最大幅は隣接キャラまでの距離から計算し、上部バー・編成切替欄へ入り込まない位置に制限します。320×640から1600×900まで8種類のサイズで確認します。

## 負荷と生命周期

タイトルではモデルを取得せず、WebGLも作成しません。HOMEで独立したロビー用rendererを1つ作成し、GLB2点を初回だけ読み込みます。描画は最大30fps、DPRは標準で最大1.5、軽量で1です。4人のモデルはgeometry・material・textureを共有します。待機動作は提供されたIdleの実データを再生し、床と足の位置を保ちます。

画面を離れたときとタブ非表示時は描画を停止します。ユーザーまたはOSの動き軽減では必要な変更時だけ描画します。骨格を作り直すときは古いbone textureを解放します。破棄時にはrenderer、モデル資源、ResizeObserverとイベントを解放します。

本編用rendererは出撃前確認まで作成しません。ロビーの描画が本編の進行や物理更新を代行することはありません。

## ファイル

`src/home-lobby.ts`が画面状態と保存を接続し、`home-lobby-scene.ts`がモデルとステージ、`home-lobby.css`がUIを扱います。通常配信では`public/home-models/*.glb`をHOME表示時に読み込みます。

`npm run package:preview`はGLBのハッシュと外部依存の有無を確認し、単独HTMLにモデルを埋め込みます。マップは圧縮データとして同梱し、開くときだけ展開します。`release/RECLAIM_Home_Lobby_Preview.html`はHOMEから開くプレビューで、ネット接続なしでもキャラクターとマップを表示します。提供用のHTML・確認画像はワークスペースの`home`フォルダへ配置します。


## 知床の倉庫・増援（2026-10-27更新）

家から既存倉庫へ向かう林道の約46%地点に中継倉庫を追加。既存の地形・家・倉庫・植生は残し、道路接続と歩いて入れる入口を備える。

最初から道にいた2体は廃止し、操作中のゲーム時計で各倉庫から5秒おきに1体ずつ出現する。両方とも人型→ドローンを交互に出し、奥の既存倉庫は20体、中継倉庫は30体まで。両倉庫が健在なら100秒で20体＋20体、150秒で20体＋30体の計50体になる。会話・一時停止・非表示中は時計を止める。

製造装置は各倉庫に人型用とドローン用を1台ずつ、計4台。それぞれHP500。破壊するとその倉庫の同型増援だけを止め、別倉庫には影響しない。死亡後の家への復帰で4台・敵の時計・出現数をリセットする。

アサルトとスナイパーは予備弾無制限（HUDは∞）。弾倉24発・5発、リロード1.8秒・2.4秒は維持する。

山麓に半径14mのボス戦用広場と既存山道からの接続を追加。動作付きの知床ボス「錆猪」「哨戒梟」を配置。山頂は変更しない。

## 知床ボス（2026-10-27更新）

motion/characters/錆猪・哨戒梟の完成した動作付きGLBを配信用にそのままコピーし、Idle・Walk・Chase・Attack・Hit・Deathを再生する。元モデルと動作ファイルは変更しない。錆猪はHP2000、哨戒梟はHP1500。ボスは山麓の広場内を巡回し、プレイヤーが近づくと追跡・攻撃する。攻撃には予備動作があり、範囲外・遮蔽物越しにはダメージを与えない。

頭上に追従するHPバーと、画面左側に名前・現在/最大HPを持つ2体分の一覧を表示。射撃・近接・ダメージ数字・撃破表示は同じHPを参照し、再挑戦で両方を初期化する。左一覧は目標欄の直下へ追従し、頭上バーとモデルは距離で描画を抑える。会話・一時停止中はAIとアニメーションを停止する。

通常配信はpublic/mission-bosses/から読み込み、単独HTMLは両GLBとMeshoptデコーダーを内包する。追加のCDNやWASMの通信は不要。
