- z=-4240〜-4560mで旧頭壁を300〜400m幅の海岸丘陵/崖錐へ遷移。20m接合の前後40mと±5mの法線プローブを保護。海岸線の17m成分を除き、60m成分は20%へ減衰。270mの入り江・半島の形を保持する。

- 実辺高差はp95約31.09m、p95法線角約17.19度へ減少。最大166.49mの急な辺は凍結した接合直後に残る。最大勾配は細分化で旧の粗い平均値より大きくなるため、最大勾配だけを品質スコアにしない。座標と上位20辺をJSONへ残す。

## 地形契約

| 項目 | 実装 |
| --- | --- |
| 徒歩範囲 | X/Z −1200…1200m、1単位=1m |
| メッシュ | 300m×300m×8×8、64チャンク、5m頂点間隔 |
| 高さデータ | 481×481、231,361個のFloat32値 |
| 住宅予定地 | (−170,850)、海抜108m、約28m半径の平坦な中心部 |
| 湿原の主要地点 | (−130,410)、海抜92m。森林・建物なしで低地が見える |
| 湖 | 不規則な湖岸、149m水位、実際の湖盆。小池4か所も実際の窪地 |
| 山岳入口 | (170,−850)、海抜335m。連結する主稜線・枝尾根・D8流路による侵食谷 |
| 地形の最高点 | 約692m（グリッドの生成結果） |
| 主ルート | 約2069m片道、約4137m往復。地形上の最大勾配は約0.496 |
| 遠景 | 内陸側だけ20m間隔の簡略面。徒歩範囲との接合辺は5m頂点でステッチ |

半島輪郭は場所ごとの幅、非対称の入り江、細かな海岸変化を持つ。崖は地形メッシュ自体の大きな高低差であり、垂直面を画像で代用していない。沖の岩柱も新規地形の一部である。山岳を円錐プリミティブの列にせず、接続した稜線と侵食谷から構成する。

地形生成は固定seedで再現可能。地面への接地は描画と同じ5m格子・同じ対角線の三角形補間を使う。全64チャンクの境界位置・法線を検査する。ルートの地形整形は周囲との高度差に応じて広げ、山腹に不自然に細い溝ができることを抑える。

5m面は今回の全徒歩範囲に保持する。遠景だけ20mへ簡略化し、視錐台カリングを使用。動的な近景LOD・ストリーミングはPhase 5の作業として残す。高さはCPU上で約0.88MiB。GPU属性・フレームバッファ等をこの値に含めない。

水面と光は湖盆・海岸・凹凸を読むための仮表示。反射、植生、波打ち際、PBR素材の最終仕上げをPhase 2/4完了とは扱わない。

俯瞰の静止中はGPUへの同一フレーム再送を止め、カメラ・表示・サイズ変更時だけ描画する。徒歩は継続描画。水面の時間変化を目的に俯瞰を毎フレーム描画する仕様にはしない。検証では静止15 RAF中の描画回数が増えないことも確認する。マウスロック取得時は取得直後のキー入力を消さず、ロック解除時には入力をクリアして俯瞰へ戻る。

## 検証

```sh
npm run typecheck
npm test
npm run build
npm run test:blender
node scripts/package-shiretoko-terrain.mjs
# RECLAIM_TEST_BROWSER は必要な環境だけ設定
node scripts/verify-shiretoko-terrain.mjs
```

`tests/shiretoko-terrain.test.mjs` は再現性、64チャンクの全接合、描画面と接地、湖盆、水域の禁止、全ルートの勾配、実移動処理による往復、ジャンプを検査する。中間地点へのteleportで移動検証を省略しない。

ブラウザ検証は、実際の単体HTMLを `file://` で開く。実WebGLのシェーダーコンパイル、1600×1000と1366×768のPC操作領域、全景・4地点の描画、Pointer Lock、実W入力、ジャンプ、Escape、標高・ルート切替を確認する。さらに同じブラウザ内のWalkerを固定60Hzで主ルート全体に通し、約4.1kmの往復と接地を検査する。この全距離は入力シミュレーションであり、4.1kmを実時間にキーボードで歩いた性能試験とは区別する。

`release/shiretoko-phase1-review/verification.json` に検査結果、生成時間、初回描画、draw calls、三角形数、frame interval、heapの取得可能値を保存する。ソフトウェアSwiftShaderによるheadless Chromiumの計測であり、物理Windows PCのFPS/VRAMや60fpsを保証しない。外部ネットワーク要求とStorageへのアクセスはゼロを要求する。明示的なdisposeも検証する。
