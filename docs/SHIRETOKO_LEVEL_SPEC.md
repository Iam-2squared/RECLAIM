# 知床・北海道ワールド / 開発仕様

## 現在の体験

初回起動は灰色の東京TITLE。HOME V2のSTARTは出撃前確認を開き、`出撃開始`を押した時だけ知床MISSIONへ入る。木造家屋の室内で目覚め、ラジオ、日本各地のAI暴走の報道、東京の親友からの連絡、玄関から出発、森の小型偵察ドローン、林道の道標という順序。

オープニングは短いテキストと操作を組み合わせる。起床・報道・連絡を明示操作でスキップできるが、家を出ること、敵撃破、経路通過をスキップによって付与しない。読み込み直後やHOMEから勝手にPointer Lockしない。未到達地名や後半の東京展開はマップ・ボスパネルで伏せる。

家、ラジオ、寝床、森、湖岸の遊歩道、岩、遠景山は自作形状。測量された知床や実際の北海道登山経路の再現ではなく、ユーザー指定の物語の旅行順に沿う。地域内の歩ける地形は480m×480m、最初のロード範囲は48mチャンクのLow3×3 / Balanced5×5。先の全域が完成した主張はしない。

## 操作

| キー / UI | 実動作 |
| --- | --- |
| 出撃開始 | 選択した解放済み区間の起点へ。初回は知床のみ。 |
| 保存位置から再開 | 同じ区間の安全なチェックポイントへ。初回ロードはTITLEのまま。 |
| 探索を開始 | 明示クリック / Enter / SpaceでPointer Lock要求。 |
| WASD | 視点に対する徒歩移動。斜めの速度は正規化。 |
| マウス | 一人称のyaw/pitch。ロック開始時のカーソル移送を除外。 |
| 矢印キー | 視点の小刻みな調整。 |
| Shift | ダッシュ。北海道に運転操作はない。 |
| Space | 接地時ジャンプ。押しっぱなしで連続ジャンプしない。 |
| E | 実際にラジオの2.4m以内から報道を確認。 |
| 左クリック | 選択した手持ち銃による射撃。導入を終えて出発した後。 |
| Esc / 一時停止 | Pointer Lock解除、入力クリア、シミュレーション停止。 |
| 保存してHOMEへ | 安全な進行・位置を保存してワールドを破棄。 |
| 表示設定 | 既存Low/Balancedを森林密度・表示距離・解像度に適用。 |

テキスト/ポーズ中はボタンのEnter/Spaceを維持。Tabや表示設定はHOME同様に操作可能。マウスロックを拒否する環境は明示エラーを表示してHOMEへ戻れる。モバイルのTITLE/HOME導線を維持するが、MISSIONはPCキーボード＋マウス用で、タッチ用FPS操作は未実装。

## 安全な移動

- 足位置・地形描画は同じ2m格子の三角補間。近景は2m、遠景だけ8mに落とす。
- 固定60Hzシミュレーション、RAF描画を分離。1フレームの実時間入力は最大0.1秒、最大6ステップ。長いRAF遅延を全追跡しない。メニューの30fps制限を操作中へ適用しない。
- キャラクター半径0.32m / 高さ1.76m、視点1.62m。家・寝床・ラジオ台・樹木・岩・廃車などのAABB/円柱を共有。小さな移動分割で壁抜けを防ぐ。
- 湖・急斜面は進入を拒否。場外や無効位置では実際の起点へ戻す。保存位置が水中・急斜面・壁内なら拒否して安全な起点を採用。
- Esc、Pointer Lock喪失、ウインドウのblur、非表示タブでは停止。戻っても勝手に操作再開しない。
- HOMEへ戻るとMISSIONの入力リスナー、敵モデル、カメラ武器、チャンク、素材、音の短い効果を解放。遅れて成功するロック要求もHOMEでは解除。

## 初敵 / PROVISIONAL

`COMBAT_TUNING`と`WEAPON_TUNING`は仮の開発値。バランス確定・装備所有権・レアリティ性能ではない。

| 仮値 | 現在 |
| --- | ---: |
| プレイヤーHP | 100 |
| 小型偵察ドローンHP | 24 |
| 弱い攻撃 | 4 / 2.4秒 |
| 索敵 / 攻撃距離 | 23m / 8m |
| 追従速度 / 係留範囲 | 1.1m/s / 16m |
| アサルト / 小銃 / スナイパーの1発 | 8 / 8 / 12 |
| 射撃間隔 | 0.20 / 0.38 / 0.65秒 |

敵は待機→索敵→追従→小攻撃→離脱、HP0で停止。自律制御はローカルの決定論的NPCで、生成AI APIを使わない。遮蔽物・地形を考慮した射線と敵球の交差を使い、空振りでHPを減らさない。見かけの射撃成功を返さない。撃破は実HP0と実被弾回数から進行へ記録。未完了の導入中は攻撃/射撃進行を止め、先に敵を破壊して任務が詰まることを防ぐ。

被弾ではプレイヤーHPと画面縁の表示が変化。HP0は明示し、再挑戦で実際の起点・体力を復帰し、その位置を再保存する。日本刀の近接攻撃、銃のリロード/弾薬・副武器切替、装備強化は未実装。手持ち銃の選択はHOMEのプレビューを読み込み、仮性能としてのみ使用する。

## 未確定の物語・制作境界

親友の名前・声優・通話方式、放送局・日時・声、正式な地域の任務/難易度/報酬は未確定。テキスト・データにPROVISIONALを残し、既存の通信・自律制御を信用できない世界から実ネットワーク通話を作らない。自作の短い音のみ、音ONの時だけ再生。第三者BGM/画像/音声/TTSなし。

知床は導入のプレイ可能なプロトタイプ、3区域は環境プロトタイプ。人型AI・大ボス・実協力・共有ボスHP・3ウォール・ランキング・ログイン・DB・乗り物は未実装。Fab GLB/ユーザーのv02は未提供なのでゲーム用形状へ混入させていない。

## 報告しやすい再現手順

1. 配布HTMLをPC Chromeで開く。TITLE→HOME→START→出撃開始。
2. 起床→探索開始。ラジオの前へ歩きE→連絡→出発。
3. 玄関から林道へ。敵に照準を合わせて左クリック。実HPと停止を確認。
4. 道標まで歩いてHOMEへ戻る。マップの名称公開と再出撃/保存位置再開を確認。
5. 問題はHTMLのsource SHA、OS/Chrome、viewport、品質、直前の操作、スクリーンショット、再現率を添えて報告する。

画面外UI・壁/地形抜け・照準と被弾の不一致・進行の不一致・2回目以降の挙動・重さはそれぞれ報告対象。`window.__RECLAIM__.snapshot()`は読取専用で、画面、位置/接地/キー、敵状態、進行、チャンク、renderer資源とCPU送信時間を確認できる。物理Windows PCの性能は未測定。
