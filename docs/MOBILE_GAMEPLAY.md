# スマホで本編を遊ぶ

2026-10-27 軽量化更新。現在のPC公開版 `e3ab66a` を基点に、`codex/mobile-playable-20261027` で独立して実装します。main、PC版の公開ブランチ、既存PC版の公開URLは更新しません。タッチ対応版は別のHTTPS Previewで提供し、端末の保存もURLごとに分かれます。

## 起動

スマホ対応版: **https://reclaim-mobile-preview.vercel.app/**

iPhoneはSafari、AndroidはChromeで配信URLを開き、START → HOMEのプレイ → 出撃開始 → 起き上がる → 探索を開始と進みます。スマホの「ファイル」内のHTMLプレビューは使いません。導入を読むかスキップするかは従来どおり選べます。横向きを推奨しますが、縦向きでも操作できます。

WebGL2が必要です。利用できない場合はHOMEまで操作でき、出撃を開始しません。保存済みの描画設定がないタッチ専用端末は軽量描画で起動します。描画設定は後から変更できます。

## タッチ操作

| 操作 | 画面 |
| --- | --- |
| 前後左右へ移動 | 左スティックを動かす |
| 視点 | 右側の空いた領域をスワイプ |
| 射撃・近接 | 射撃ボタンを押す。アサルトは長押しで連射 |
| 構え | 構えボタンで切替 |
| ジャンプ | ジャンプボタン |
| ダッシュ | 左スティックを大きく前へ倒す |
| 装填 | 弾切れ時は自動。途中の装填は武器長押し → 装填 |
| 武器 | 武器ボタンで主副切替。長押しの装備パネルからナイフも選択 |
| 一人称・三人称 | 武器長押し → 視点 |
| ラジオを調べる | 調べるボタン。近づいてから操作 |
| 一時停止 | 停止ボタン |
| 保存して戻る | 一時停止 → 保存してHOMEへ |

通常表示は移動スティック、射撃、構え、ジャンプ、武器、一時停止の6つです。武器はタップで主副を切り替え、長押しで装填・武器一覧・ナイフ・視点切替の装備パネルを開きます。

移動・視点・射撃は複数の指で同時に操作できます。画面回転・一時停止・タブ非表示・入力キャンセル・HOMEへの帰還では保持入力を解除します。探索の再開は明示的に「探索を開始」で行います。マウス固定は要求しません。

ゲームの移動速度、衝突、武器、弾薬、射撃間隔、敵、ボス、進行条件はPCと共通です。オンライン機能は未接続です。PCのキーボード・マウス操作も利用できます。

## スマホの描画・読み込み

- スマホ用の地形配信データは約7.1MB（元のビューア約54.1MB）。地形・衝突・建物・木・進行判定の数値は元データと一致します。
- 地形画像は最大1024px。近い地形と建物は元の三角形を維持し、遠い植生は軽い形状へ切り替え、小さい草の密度を下げます。遠景は霧で隠してから描画対象外にします。
- スマホではMSAAを使わず、軽量描画の解像度倍率0.6、描画は最大約30fps。移動・衝突・武器・敵の物理更新は従来の60Hzです。
- 最初は今使う銃だけを読み込み、未使用の武器・一人称で見えない自分のモデル・遠方の敵やボスは必要時に読み込みます。
- HOMEは保存済みの編成がなければソロ、必要なキャラだけを読み込みます。出撃中はHOMEの描画用GPU資源を解放し、戻る時はキャッシュ済みのモデルを再利用します。

配信データの再生成・検証は `python3 scripts/build-mobile-map.py --check`。Python/Pillowはこの開発用の生成にだけ使い、Vercelの配信ビルドやユーザー端末には不要です。元の `shiretoko.html` は書き換えません。

## 検証

```sh
npm ci
npm run typecheck
npm test
npm run build
RECLAIM_TEST_BROWSER=/usr/bin/chromium npx playwright test --config=scripts/mobile-mission-playwright.config.mjs
```

モバイルChromiumとWebKitで、通常のタイトルからの出撃、実際の位置・視点変化、武器操作、一時停止時の入力解除、HOMEへの帰還、縦横の配置を確認します。Chromiumではブラウザのタッチ入力、WebKitではタップとPointerEventによるドラッグを使用します。物理iPhone/AndroidのGPU性能、熱、電池消費、iOS実機そのものの動作を測定済みとは扱いません。
