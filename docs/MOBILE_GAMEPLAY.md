# スマホで本編を遊ぶ

2026-10-27。現在のPC公開版 `e3ab66a` を基点に、`codex/mobile-playable-20261027` で独立して実装します。main、PC版の公開ブランチ、既存PC版の公開URLは更新しません。タッチ対応版は別のHTTPS Previewで提供し、端末の保存もURLごとに分かれます。

## 起動

iPhoneはSafari、AndroidはChromeで配信URLを開き、START → HOMEのプレイ → 出撃開始 → 起き上がる → 探索を開始と進みます。スマホの「ファイル」内のHTMLプレビューは使いません。導入を読むかスキップするかは従来どおり選べます。横向きを推奨しますが、縦向きでも操作できます。

WebGL2が必要です。利用できない場合はHOMEまで操作でき、出撃を開始しません。保存済みの描画設定がないタッチ専用端末は軽量描画で起動します。描画設定は後から変更できます。

## タッチ操作

| 操作 | 画面 |
| --- | --- |
| 前後左右へ移動 | 左スティックを動かす |
| 視点 | 右側の空いた領域をスワイプ |
| 射撃・近接 | 射撃ボタンを押す。アサルトは長押しで連射 |
| 構え | 構えボタンで切替 |
| ジャンプ | ジャンプボタン |
| ダッシュ | ダッシュボタンで切替 |
| 装填 | 装填ボタン |
| 武器 | 主武器・副武器・ナイフ |
| 一人称・三人称 | 視点ボタン |
| ラジオを調べる | 調べるボタン。近づいてから操作 |
| 一時停止 | 停止ボタン |
| 保存して戻る | 一時停止 → 保存してHOMEへ |

移動・視点・射撃は複数の指で同時に操作できます。画面回転・一時停止・タブ非表示・入力キャンセル・HOMEへの帰還では保持入力を解除します。探索の再開は明示的に「探索を開始」で行います。マウス固定は要求しません。

ゲームの移動速度、衝突、武器、弾薬、射撃間隔、敵、ボス、進行条件はPCと共通です。オンライン機能は未接続です。PCのキーボード・マウス操作も利用できます。

## 検証

```sh
npm ci
npm run typecheck
npm test
npm run build
RECLAIM_TEST_BROWSER=/usr/bin/chromium npx playwright test --config=scripts/mobile-mission-playwright.config.mjs
```

モバイルChromiumとWebKitで、通常のタイトルからの出撃、実際の位置・視点変化、武器操作、一時停止時の入力解除、HOMEへの帰還、縦横の配置を確認します。Chromiumではブラウザのタッチ入力、WebKitではタップとPointerEventによるドラッグを使用します。物理iPhone/AndroidのGPU性能、熱、電池消費、iOS実機そのものの動作を測定済みとは扱いません。
