## 開発

動作データの編集元はリポジトリと同じ階層の`motion/characters/<キャラ名>/`、確認用は`motion/キャラ動作確認.html`です。元の静止モデルは`character/`に保存します。`npm run package:motion`で確認用HTMLを更新し、`npm run test:motion`でオフライン動作を検証します。検証画像・ログは`motion/reports/`へまとめます。フォルダの詳細は`motion/README.txt`を参照してください。

Node.js 22.16以上を使用。

```sh
npm ci
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

```sh
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:e2e
npm run package:preview
npx playwright test --config=scripts/mobile-playwright.config.mjs
```

## 操作

- **START（タイトル）**：HOMEへ。CONTINUEは有効なcheckpointがある場合だけ出撃前確認へ。再読込は必ずタイトルから始まり、戦闘へ直接入りません。
- **SETTINGS / INFORMATION**：表示品質・動き軽減・音、ゲームの開発版について確認。設定内にも音ボタンがあります。
- **ソロ / 4人編成 / 空き枠の＋**：実モデルを1～4体表示。参加者の表示はローカルの編成プレビューで、オンラインには接続しません。
- **マップ**：18地点の順序を保持。知床と札幌へ直接出撃できます。未到達地名/説明は???、実達成で道中の区間を順次公開。
- **キャラ設定**：表示名と画面アクセントを変更。左のオペレーター選択でJonesy/Ramirezの実モデルを切り替えます。服・装備の元の質感は維持します。
- **武器**：`weapon`内の新しいアサルト／スナイパーを主・副武器に、サバイバルナイフを近接枠に表示します。新モデルのプレビューを掲載し、以前の小銃の保存は現在の銃へ移行します。ロビーのキャラクターは武器を持たない立ち姿です。
- **今のボス状況／ランキング**：未接続の空状態。架空のHPや順位を表示しません。
- **START（HOME）**：出撃前確認を開くだけで保存・開始しません。PCでは明示的な出撃開始／安全な保存位置から再開。スマホ幅・低い横画面・広幅のタッチ専用端末ではPC操作が必要と案内して開始前に停止し、checkpointを変更しません。
- **小さい画面**：メニューから同じ5項目へ。Escapeで閉じ、元のボタンへフォーカスが戻ります。
- **右上**：音のオン/オフ、軽量描画、背景の動きの抑制。音は初期状態でオフ。

## 技術上の境界

- 静的配信のみ。サーバー、DB、APIキー、決済、マッチングなし。
- TITLEは2D画像＋DOM、CSS演出でWebGLなし。HOMEは実GLBと独立した最大30fpsの軽量rendererを使い、非表示時は停止します。MISSIONは別のRAF描画と固定60Hzの操作更新を分離します。
- InstancedMeshによる静的部材の集約。動的な雲・影・破壊物理・ポスト処理はなし。
- タブ非表示時は描画を停止。環境音も一時停止。
- 外観・装備はプレビュー専用キー。campaignは独立したversion1キーへ実際の導入/撃破/通過/位置を保存。端末ローカルで、認証や改ざん防止保証はありません。拒否された場合もセッション内で操作できます。
- 他のPractice / GlobeQ / ARK / Ark Terminalリポジトリは対象外。
